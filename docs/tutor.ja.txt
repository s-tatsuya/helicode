              Helicode チュートリアルへようこそ！
        j キーを押し続けて「はじめに」まで進んでください。


 このチュートリアルは Helix 付属の tutor を日本語にしたものです。
 演習に使う行は英語のままにしてあります。w / e / b などの単語移動は
 英数字と記号の区切りを前提にしているため、その挙動をそのまま試せる
 ようにするためです。


=================================================================
=                          はじめに                             =
=================================================================

 Helix は「モーダル」なエディタです。つまり、編集のためのモードが
 いくつかあり、モードによって同じキーの意味が変わります。よく使うのは
 ノーマルモードと挿入モードです。ノーマルモードでは、打ったキーは
 文字として入力されず、テキストに対する操作になります。これにより
 少ないキー数で編集できます。

 Helicode は、この Helix の編集モデルを VS Code 上で再現した拡張機能
 です。以降の説明の「Helix」は、そのまま Helicode にも当てはまります。

 まずは CapsLock が押されていないことを確かめ、j キーを押し続けて
 最初のレッスンまで進んでください。

 このチュートリアルは名前のないバッファで開いています。
 * 保存せずに閉じるには :q! と入力します。
 * ファイルに保存するには :w <パス> のあと :q と入力します。

 VS Code 特有の操作は、最後の第 14 章にまとめてあります。






=================================================================
=                    1.1 カーソルの基本移動                     =
=================================================================

          ↑
          k       * h は左
      ← h   l →   * l は右
          j       * j は下向きの矢印に見える
          ↓

 カーソルは h, j, k, l キーで動かせます。矢印キーでも動きますが、
 hjkl のほうがホームポジションから手を離さずに済むので速く打てます。
 まずは hjkl で自由に動き回ってみてください。

 慣れたら j を押し続けて次のレッスンへ進みます。







=================================================================
=                    1.2 Helix を終了する                       =
=================================================================

 1. : を入力してコマンドモードに入ります。入力欄が開きます。
 2. q または quit と入力して Enter を押すと終了します。

 注意: 保存していない変更があると quit は失敗します。
       変更を捨てて強制終了するには q! または quit! と入力します。
       保存の方法はあとのレッスンで学びます。

 コマンドを実行せずにコマンドモードを抜けるには Escape を押します。

 Helicode では :q は VS Code のエディタタブを閉じます。

 次のレッスンへ進みましょう。




=================================================================
=                         1.3 削除する                          =
=================================================================

 d キーを押すと、カーソルの下の文字が削除されます。

 1. '-->' の付いた行にカーソルを移動します。
 2. 余分な文字までカーソルを動かし、d を押して削除します。

 --> Thhiss senttencee haass exxtra charracterss.
     This sentence has extra characters.

 文が正しくなったら次のレッスンへ進みます。







=================================================================
=                       1.4 挿入モード                          =
=================================================================

 i キーを押すと挿入モードに入ります。

 1. '-->' の付いた行にカーソルを移動します。
 2. 文字が足りない位置へ移動し、i を押して挿入モードに入ります。
    ここから打ったキーは文字として入力されます。
 3. 足りない文字を入力します。
 4. Escape を押して挿入モードを抜け、ノーマルモードに戻ります。
 5. 下の行と一致するまで繰り返します。

 --> Th stce misg so.
     This sentence is missing some text.

 注意: 現在のモードはステータスバーに表示されます。
       i を押すと 'NOR' が 'INS' に変わります。



=================================================================
=                      1.5 ファイルを保存する                   =
=================================================================

 :w または :write と入力するとファイルを保存します。

 1. VS Code で編集したいファイルを開きます。
 2. 適当に編集します。
 3. : を入力してコマンドモードに入ります。
 4. w または write と入力して Enter を押すと保存されます。

 wq または write-quit で、保存してから閉じることもできます。

 注意: w / write のあとにパスを書くと、そのパスに保存できます。
 注意: 未保存の変更があると、VS Code のタブに丸印が表示されます。




=================================================================
=                        第 1 章のまとめ                        =
=================================================================

 * h, j, k, l キーでカーソルを移動する。

 * : でコマンドモードに入る。
   * q / quit と q! / quit! は Helix を終了する。前者は未保存の変更が
     あると失敗し、後者は変更を捨てる。
   * w / write はファイルを保存する。
   * wq / write-quit は保存して終了する。

 * d でカーソル位置の文字を削除する。

 * i で挿入モードに入って文字を入力し、Escape でノーマルモードに戻る。




=================================================================
=                  2.1 そのほかの挿入コマンド                   =
=================================================================

 i でカーソル位置の手前から挿入モードに入れることは学びました。
 ほかにも挿入モードに入る方法があります。

 よく使うのは次の 4 つです。
   i - 選択範囲の前に挿入する。
   a - 選択範囲の後ろに挿入する (append の a)。
   I - 行頭に挿入する。
   A - 行末に挿入する。

 1. '-->' の付いた行のどこかにカーソルを移動します。
 2. A (Shift-a) を押すと、カーソルが行末に移動して入力できます。
 3. 下の行と一致するように文字を入力します。

 --> This sentence is miss
     This sentence is missing some text.

=================================================================
=                      2.2 行を追加する                         =
=================================================================

 o を押すと、カーソルの下に改行を追加して挿入モードに入ります。
 O を押すと、カーソルの上に改行を追加して挿入モードに入ります。

 1. '-->' の付いた行にカーソルを移動します。
 2. o を押して下に行を開き、答えを入力します。

 --> 一番良いエディタは何ですか？











=================================================================
=                        第 2 章のまとめ                        =
=================================================================

 * a で選択範囲の後ろに追記する。

 * I で行頭 (最初の非空白文字) から挿入モードに入る。

 * A で行末から挿入モードに入る。

 * o と O でカーソルの下 / 上に行を開く。











=================================================================
=                   3.1 移動と選択                              =
=================================================================

 w を押すと、次の単語の手前まで選択します。

 d キーは実際には「カーソル位置の文字」を消しているのではなく、
 「選択されているテキスト」を消しています。カーソルは 1 文字分の
 選択範囲だと考えてください。

 1. '-->' の付いた行にカーソルを移動します。
 2. 削除したい単語の先頭へ移動します。
 3. w を押して次の単語の先頭まで選択します。
 4. d を押して選択範囲を削除します。
 5. 余分な単語すべてについて繰り返します。

 --> This sentence pencil has vacuum extra words in the it.
     This sentence has extra words in it.




=================================================================
=                     3.2 そのほかの移動                        =
=================================================================

 w は次の単語の先頭まで前進し、通過したテキストを選択します。
 移動にも、操作対象の選択にも使えます。

 よく使う移動は次のとおりです。
   w - 次の単語の先頭の手前まで前進する。
   e - 現在の単語の末尾まで前進する。
   b - 現在の単語の先頭まで後退する。

 カーソル下の単語を選択するには e と b を組み合わせます。

 1. '-->' の付いた行にカーソルを移動します。
 2. 'd' の文字へ移動します。
 3. e を押して単語の半分を選択します。
 4. b を押して残りを選択します。

--> The Middle Kingdom.

=================================================================
=                     3.3 word と WORD                          =
=================================================================

 w, e, b には W, E, B という大文字版があり、word ではなく WORD を
 対象にします。WORD は空白だけで区切られますが、word は記号でも
 区切られます。

 1. '-->' の付いた行の先頭にカーソルを移動します。
 2. w を繰り返し押して、行末まで単語ごとに選択します。
 3. 'one-of-a-kind' を通過するのに 7 回、'"modal"' に 3 回
    かかることを確かめます。
 4. もう一度行の先頭に戻ります。
 5. W を繰り返し押して WORD ごとに選択します。
 6. 'one-of-a-kind' も '"modal"' も 1 回で選択できることを確かめます。

--> Helix is a one-of-a-kind "modal" text editor


=================================================================
=                    3.4 change コマンド                        =
=================================================================

 c を押すと、現在の選択範囲を変更します。

 change は選択範囲を削除して挿入モードに入るので、d の後に i を
 押すのと同じです。とてもよく使います。

 1. '-->' の付いた行にカーソルを移動します。
 2. 間違っている単語の先頭へ移動し、e を押して選択します。
 3. c を押して単語を削除し、挿入モードに入ります。
 4. 正しい単語を入力します。
 5. 下の行と一致するまで繰り返します。

 --> This paper has heavy words behind it.
     This sentence has incorrect words in it.




=================================================================
=                   3.5 回数を指定した移動                      =
=================================================================

 移動の前に数字を入力すると、その回数だけ繰り返します。

 1. '-->' の付いた行にカーソルを移動します。
 2. 2w で 2 単語進みます。
 3. 3e で 3 つ先の単語の末尾まで進みます。
 4. 2b で 2 単語戻ります。
 5. いろいろな数字で試してみます。

 --> This is just a line with words you can move around in.









=================================================================
=                    3.6 セレクトモード                         =
=================================================================

 v を押すとセレクトモードに入ります。
 もう一度 v を押すか Escape を押すとノーマルモードに戻ります。
 セレクトモードでは、すべての移動が選択範囲を置き換えるのではなく
 「広げる」動きになります。

 1. '-->' の付いた行にカーソルを移動します。
 2. FOO の F へ移動し、v2w で 2 単語を選択します。
 3. d で 2 単語を削除します。d を押すとノーマルモードに戻ります。
 4. BAZ の B へ移動し、同じ手順で削除します。

 --> Remove the FOO BAR distracting words BAZ BIZ from this line.






=================================================================
=                      3.7 行を選択する                         =
=================================================================

 x を押すと行全体を選択します。もう一度 x を押すと次の行も選択します。

 1. '-->' の付いた 2 番目の行にカーソルを移動します。
 2. x で行を選択し、d で削除します。
 3. 4 番目の行へ移動します。
 4. x を 2 回、または 2x で 2 行選択し、d で削除します。

 --> 1) Roses are red,
 --> 2) Mud is fun,
 --> 3) Violets are blue,
 --> 4) I have a car,
 --> 5) Clocks tell time,
 --> 6) Sugar is sweet,
 --> 7) And so are you.

 注意: X も似ていますが、次の行までは広がりません。
       空行の上で X を押しても何も起きません。

=================================================================
=                    3.8 選択を解除する                         =
=================================================================

 ; を押すと、選択範囲を 1 文字のカーソルに畳みます。

 カーソルを動かさずに選択だけ解除したいときに使います。

 1. '-->' の付いた行にカーソルを移動します。
 2. これまでに学んだ移動で行の中を動き回り、選択されたあとに
    ; を押して解除してみます。

 --> This is an error-free line with words to move around in.

 注意: セレクトモードでも同じように動きます。
 注意: Alt-; は選択の向きを反転します (カーソルとアンカーを入れ替える)。



=================================================================
=                        第 3 章のまとめ                        =
=================================================================

 * w で次の単語の手前まで選択する。
   * e で現在の単語の末尾まで選択する。
   * b で現在の単語の先頭まで後ろ向きに選択する。
   * 大文字の W, E, B は WORD 単位で移動する。

 * d で選択範囲全体を削除する。
   * c で選択範囲を削除して挿入モードに入る。

 * 移動の前に数字を打つと、その回数だけ繰り返す。

 * v でセレクトモードに入ると、すべての移動が選択を広げる。

 * x で現在の行全体を選択する。もう一度 x で次の行も選択する。

 * セミコロン ( ; ) で選択を畳む。

=================================================================
=                       4.1 取り消しとやり直し                  =
=================================================================

 u で取り消し (undo)、U でやり直し (redo) です。

 1. '-->' の付いた行にカーソルを移動します。
 2. 最初の誤りへ移動し、d で削除します。
 3. u を押して削除を取り消します。
 4. 行の誤りをすべて直します。
 5. u を何度か押して修正を取り消します。
 6. U (Shift-u) を何度か押して修正をやり直します。

 --> Fiix the errors on thhis line and reeplace them witth undo.

 注意: Helicode の取り消しは Helix と同じ粒度です。挿入モードに入って
       Escape で抜けるまでが 1 ステップ、コマンド 1 回が 1 ステップに
       なります。VS Code 本体の取り消し履歴を使いたい場合は設定
       helicode.undo を "vscode" にします。
 注意: Alt-u / Alt-U や :earlier 10s / :later 1m で、時間をさかのぼる
       こともできます。

=================================================================
=                    4.2 コピーと貼り付け                       =
=================================================================

 y で選択範囲をヤンク (コピー) します。
 p でカーソルの後ろに貼り付けます。
 P でカーソルの前に貼り付けます。

 1. '-->' の付いた行にカーソルを移動します。
    カーソルを banana の "b" に合わせてください。
 2. w で "banana" を選択し、y でヤンクします。
 3. "2" と "3" の間の空白へ移動し、p で貼り付けます。
 4. "3" と "4" の間でも同じことをします。

 --> 1 banana 2 3 4
     1 banana 2 banana 3 banana 4

 注意: 削除や変更をすると、そのテキストは自動的にコピーされます。
       コピーしたくない場合は Alt-d / Alt-c を使います。
 注意: Helix は既定ではシステムのクリップボードを共有しません。
       Space + y / p でシステムのクリップボードを使います。

=================================================================
=                     4.3 ファイル内を検索する                  =
=================================================================

 / で前方検索し、Enter で確定します。
 n で次の一致へ、N で前の一致へ移動します。

 1. / を押して、'banana' のようによく出てくる語を入力します。
 2. Enter を押して検索を確定します。
 3. n と N で一致を行き来します。

 検索は正規表現です。select コマンドのレッスンで詳しく学びます。

 注意: 後方検索は ? (Shift-/) です。
 注意: Vim と違い、? は検索方向を変えません。
       n は常に前方、N は常に後方へ移動します。

 注意: Helicode の正規表現は JavaScript の構文です。



=================================================================
=                        第 4 章のまとめ                        =
=================================================================

 * u で取り消し、U でやり直し。

 * y でヤンク (コピー)、p で貼り付け。
   * Space + y と Space + p でシステムのクリップボードを使う。

 * / で前方検索、? で後方検索。
   * n と N で一致を行き来する。










=================================================================
=                      5.1 マルチカーソル                       =
=================================================================

 C を押すと、次の適切な行にカーソルを複製します。

 1. '-->' の付いた最初の行にカーソルを移動します。'-->' より右の
    どこかに置いてください。
 2. C を押して次の適切な行にカーソルを複製します。間の行が
    飛ばされることに注目してください。以降のキーは両方のカーソルに
    作用します。
 3. 挿入モードで行を直します。2 つのカーソルが同時に直します。
 4. , を押して最初のカーソルを取り除きます。

 --> Fix th two nes at same ime.
 -->
 --> Fix th two nes at same ime.
     Fix these two lines at the same time.

 注意: Alt-C でカーソルの上側に複製します。

=================================================================
=                     5.2 select コマンド                       =
=================================================================

 s を押すと、選択範囲の中で一致する部分を選択します。

 1. '-->' の付いた行にカーソルを移動します。
 2. x で行を選択します。
 3. s を押します。入力欄が開きます。
 4. 'apples' と入力して Enter を押すと、行内の 'apples' が両方
    選択されます。
 5. c を押して 'oranges' などに変更できます。
 6. Escape で挿入モードを抜けます。
 7. , で 2 つ目のカーソルを取り除きます。

 --> I like to eat apples since my favorite fruit is apples.
     I like to eat oranges since my favorite fruit is oranges.




=================================================================
=                   5.3 正規表現で選択する                      =
=================================================================

 検索と同じく、select コマンドも正規表現で選択します。

 1. '-->' の付いた行にカーソルを移動します。
 2. x で行を選択し、s を押します。
 3. '  +' と入力して 2 個以上連続する空白を選択し、Enter を押します。
 4. c を押して、一致した部分を空白 1 個に変更します。

 --> This  sentence has   some      extra spaces.
     This sentence has some extra spaces.

 注意: 置換をしたいときは select コマンドを使います。置換したい範囲を
       選び (% でファイル全体を選択できます)、上の手順を実行します。


=================================================================
=                      5.4 選択範囲を揃える                     =
=================================================================

 & を押すと、選択範囲の内容を揃えます。

 1. '-->' の付いた最初の行、矢印のすぐ後ろの空白にカーソルを置きます。
 2. C を 4 回、または 4C を押します。
 3. W で数字と括弧を選択します。
 4. & で揃えます。

 --> 97) lorem
 --> 98) ipsum
 --> 99) dolor
 --> 100) sit
 --> 101) amet

 注意: & が見るのは選択範囲の「head」(動くほうの端) だけです。
       もう一方の端は「anchor」と呼びます。

=================================================================
=                 5.5 選択を行ごとに分割する                    =
=================================================================

 Alt-s を押すと、選択範囲を改行で分割します。

 1. 下の表の 1 行目にカーソルを移動します。
 2. 6x で表全体を選択します。
 3. Alt-s で行ごとの選択に分割します。
 4. & で表を揃えます。

    | FRUIT   | AMOUNT |
    |---------|--------|
 | Apples  | 8      |
    | Bananas | 6      |
  | Oranges | 3      |
     | Donuts  | 4      |

 注意: macOS のターミナルでは Option を Alt として扱う設定が必要な
       場合があります。VS Code ではそのまま Option/Alt が使えます。

=================================================================
=                        第 5 章のまとめ                        =
=================================================================

 * C で次の適切な行にカーソルを複製する。Alt-C は上側。

 * s で現在の選択範囲の中から正規表現に一致する部分をすべて選択する。

 * & で選択範囲を揃える。

 * Alt-s で選択を行ごとに分割する。









=================================================================
=                 6.1 文字までを選択する                        =
=================================================================

 f<文字> でその文字まで (その文字を含めて) 選択します。
 t<文字> は同じですが、その文字は含めません。
 大文字の F / T は後ろ向きに同じことをします。

 1. '-->' の付いた行にカーソルを移動し、最初のダッシュに置きます。
 2. f[ で角括弧まで選択します。
 3. d で選択範囲を削除します。
 4. 行末へ移動し、F] で同じことをします。
 5. 2 番目の '-->' の行、矢印のすぐ後ろへ移動します。
 6. t と T でこの文の前後のダッシュを削除します。

 --> -----[Free this sentence of its brackets!]-----
 --> ------Free this sentence of its dashes!------

 注意: Vim と違い、Helix はこれらのコマンドを現在の行に限定しません。
       ファイル全体からその文字を探します。

=================================================================
=                         8.1 レジスタ                          =
=================================================================

 レジスタは、ヤンクしたテキストなどを入れておく、1 文字の名前が
 付いた入れ物です。直前の検索語やマクロもレジスタに入ります。

 "<文字> でレジスタ <文字> を選びます。

 1. '-->' の付いた行にカーソルを移動します。
 2. w で "watermelons" を選択し、y でヤンクします。
 3. w で "bananas" を選択します。
 4. "b でレジスタ b に切り替え、y でヤンクします。
 5. "mangoes" を選択し、R で "watermelons" に置き換えます。
 6. "pineapples" を選択し、"b R で "bananas" に置き換えます。

 --> I like watermelons and bananas because my favorite fruits
     are mangoes and pineapples.

 注意: Helicode では " を押すとレジスタの一覧がポップアップします。
       :registers ですべてのレジスタの中身を一覧できます。

=================================================================
=                          8.2 マクロ                           =
=================================================================

 マクロは、繰り返したい一連の操作を記録する仕組みです。
 レジスタを指定して記録することもできます (既定は @ です)。
 Q で記録を開始し、もう一度 Q で記録を終了します。
 q で @ レジスタ (または選んだレジスタ) のマクロを再生します。

 1. '-->' の付いた最初の行にカーソルを移動します。
    矢印の '>' の上に置いてください。
 2. Q を押して記録を開始します。
 3. 下の行と同じになるように編集します。
 4. 挿入モードを抜け、もう一度 Q を押して記録を終了します。
 5. 次の行へ移動し、同じように '>' の上にカーソルを置きます。
 6. q を押してマクロを再生します。

 --> ... sentence doesn't have its first and last ... .
 --> ... sentence doesn't have its first and last ... .
     This sentence doesn't have its first and last word.

=================================================================
=                        第 8 章のまとめ                        =
=================================================================

 * " で別のレジスタを選ぶ。

 * Q でマクロの記録を開始 / 終了する。既定のレジスタは @。

 * q で @ または選んだレジスタのマクロを再生する。












=================================================================
=                  9.1 選択範囲を検索する                       =
=================================================================

 / による直前の検索はレジスタ / に入ります。
 n と N はどちらもレジスタ / を参照するので、検索を打ち直さずに
 このレジスタを設定できます。

 * を押すと、選択範囲をレジスタ / にコピーし、検索語にします。
 コピーされるのはプライマリ選択です (次の章で学びます)。

 1. '-->' の付いた行にカーソルを移動します。
 2. e で "horse" を選択し、* を押します。
 3. n と N で "horse" を行き来します。

 --> A horse is a horse, of course, of course,
 --> And no one can talk to a horse of course.

 注意: * は "/y の短縮形のようなものです。選択範囲を / レジスタに
       コピーしているだけです。

=================================================================
=           9.2 次の一致に選択を追加する                        =
=================================================================

 セレクトモード (v) で n と N を使うと、選択を移動するのではなく、
 一致するたびに選択が追加されます。

 1. '-->' の付いた行にカーソルを移動します。
 2. 最初の "bat" を選択し、* で検索語にします。
 3. v でセレクトモードに入ります。
 4. n でもう一方の "bat" も選択します。
 5. c (または "b" を選択してから r) で "bat" を "cat" に変えます。

 --> Everybody wants to be a bat,
 --> because a cat's the only bat
 --> who knows where it's at.




=================================================================
=                    9.3 ジャンプリストを使う                   =
=================================================================

 Helix は、検索や定義へのジャンプといった大きな移動を「ジャンプ」と
 して記録します。この記録をジャンプリストと呼びます。

 Ctrl-s で現在の位置を手動でジャンプリストに保存します。

 Ctrl-i ("in") と Ctrl-o ("out") でジャンプリストを前後に移動します。

 1. どこかで Ctrl-s を押します。
 2. ファイルの遠くへ移動します。
 3. Ctrl-o を 1 回だけ押して、保存した位置へ戻ります。

 注意: Helicode のジャンプリストはファイルをまたいで共有されます。



=================================================================
=             9.4 2 文字ラベルでジャンプする                    =
=================================================================

 gw を押すと 2 文字のラベルが表示されます。各単語の先頭が 2 文字の
 強調表示に置き換わります。表示された 2 文字を入力するとその単語へ
 ジャンプします。Escape でラベルを消します。

 1. '-->' の付いた行の先頭にカーソルを移動します。
 2. gw を押してラベルを表示し、'here' の先頭の 'he' を置き換えている
    2 文字を入力してジャンプします。

 --> This is just a simple line of text.
     There may be many such lines
     But you really want to jump here!
     This is fast with the 2-character labels.

=================================================================
=                        第 9 章のまとめ                        =
=================================================================

 * * でプライマリ選択を検索レジスタに設定する。

 * セレクトモードで n / N を使うと、一致するたびに選択が追加される。

 * Ctrl-s で現在位置をジャンプリストに保存する。
   * Ctrl-i と Ctrl-o でジャンプリストを前後に移動する。

 * gw で 2 文字ラベルを表示し、2 文字を入力してジャンプする。
   Escape でラベルを消す。

=            10.1 選択を巡回する / 取り除く                     =
=================================================================

 ) と ( で、プライマリ選択を前後に巡回させます。

 Alt-, でプライマリ選択を取り除きます。

 1. '-->' の付いた行にカーソルを移動します。
 2. xx または 2x で 2 行を選択します。
 3. s を押し、"would" と入力して Enter を押します。
 4. ( と ) でプライマリ選択を巡回させ、2 つ目の "would" を
    Alt-, で取り除きます。
 5. c "wood" で残りの "would" を "wood" に変更します。

 --> How much would would a wouldchuck chuck
 --> if a wouldchuck could chuck would?

 注意: テーマによってはプライマリ選択が見分けにくいことがあります。
       ステータスバーで選択数を確認できます。

=================================================================
=            10.2 選択の中身を巡回させる                        =
=================================================================

 Alt-) と Alt-( で、選択範囲の中身を前後に入れ替えます。

 1. '-->' の付いた行にカーソルを移動します。
 2. xx または 2x で 2 行を選択します。
 3. s を押し、"through|water|know" と入力して Enter を押します。
 4. Alt-( と Alt-) で選択範囲の中身を巡回させます。

 --> Jumping through the water,
 --> daring to know.








=================================================================
=                     10.3 大文字小文字を変える                 =
=================================================================

 ~ で選択中の文字の大文字小文字を反転します。
 ` で選択中の文字をすべて小文字にします。
 Alt-` ですべて大文字にします。

 1. '-->' の付いた最初の行にカーソルを移動します。
 2. 大文字小文字が誤っている文字を選択し、~ を押します。
 3. 2 番目の '-->' の行へ移動します。
 4. x で行を選択します。
 5. ` で行を小文字にします。
 6. 3 番目の '-->' の行へ移動します。
 7. x で行を選択します。
 8. Alt-` で行を大文字にします。

 --> thIs sENtencE hAs MIS-cApitalIsed leTTerS.
 --> this SENTENCE SHOULD all be in LOWERCASE.
 --> THIS sentence should ALL BE IN uppercase!

=================================================================
=                   10.4 選択を分割する                         =
=================================================================

 S を押すと、各選択範囲を正規表現で分割します。

 1. --- の下の行にカーソルを移動します。
 2. xx / 2x で 2 行を選択します。
 3. S を押し、\. |! と入力して Enter を押します
    (. と ! のあとに空白があることに注意)。これで選択が文ごとに
    分割されます。
 4. Alt-; で選択の向きを反転します。
 5. ; で選択を 1 文字に畳みます。各文の最初の文字になります。
 6. Alt-` で選択中の文字を大文字にします。

---
these are sentences. some sentences don't start with uppercase
letters! that is not good grammar. you can fix this.

=                        第 10 章のまとめ                       =
=================================================================

 * ) と ( でプライマリ選択を前後に巡回させる。
   * Alt-, でプライマリ選択を取り除く。
   * Alt-) と Alt-( で選択範囲の中身を巡回させる。

 * ~ で選択中の文字の大文字小文字を反転する。
   * ` と Alt-` で小文字 / 大文字にする。

 * S で選択を正規表現で分割する。

 1. '-->' の付いた行にカーソルを移動します。
 2. その行をコメントにします。
 3. コメントを解除してみます。

 --> Comment me please

 注意: Helicode では VS Code のコメント機能を使うので、言語ごとの

=================================================================
=               11.2 複数行をコメントにする                     =
=================================================================

 選択やマルチカーソルを使えば、複数行をまとめてコメントにできます。

 * Ctrl-c でカーソルのある行をコメントにする。もう一度押すと解除。

   Ctrl-c を押す。










=================================================================
=                 12.1 マッチモードでジャンプする               =
=================================================================

 ノーマルモードで m を押すとマッチモードに入ります。括弧の対応と、
 その中身を扱うのに便利です。

 マッチモードでできることはポップアップに表示されます。対応する
 括弧へジャンプするには mm を押します。たとえば下の '-->' の行で、
 ノーマルモードのままカーソルを ( に合わせ、mm を押すと対応する )
 へジャンプします。] に合わせて mm を押せば [ へジャンプします。

 --> you can (jump between matching parentheses)
 --> or between matching [ square brackets ]
 --> now { you know the drill: this works with brackets too }

 注意: Helicode の mm は tree-sitter の構文木を使うので、文字列の中の
       括弧などを正しく扱います。文法がない言語では素朴な対応付けに
       切り替わります。

=================================================================
=            12.2 マッチモードで内側を選択する                  =
=================================================================

 マッチモードでは、括弧などの区切り文字の「内側」も選択できます。

 - '-->' の行に移動し、括弧の内側のどこか (たとえば 'x') に
   カーソルを置いて mi( または mi) を押すと、括弧の中身だけが
   選択されます (括弧自体は含みません)。あとは c で変更するなど、
   好きな操作ができます。

 --> outside and (inside x parentheses) - and outside again

 [] や {}、入れ子になった組み合わせでも同じことができます
 (すぐ外側の対応する組に作用します)。"" などでも動きます。

 --> test [ with square brackets ] !
 --> try ( with nested [ pairs of ( parentheses) and "brackets" ])

=================================================================
=            12.3 マッチモードで外側を選択する                  =
=================================================================

 ma を使うと「外側」、つまり中身と区切り文字の両方を選択します。
 下の行で括弧の間にカーソルを置き、ma( または ma) を押すと、
 () を含めて選択されます。ma(d のようにすればまとめて削除できます。

 --> you ( select x around ) to include delimiters in the select

 ほかの区切り文字でも同じように動きます。

 --> try [ with 'square' brackets ] too!

 注意: mi / ma には w (単語)、p (段落) のほか、tree-sitter を使う
       f (関数)、t (型・クラス)、a (引数)、c (コメント)、T (テスト)、
       e (要素)、x (HTML 要素)、g (git の変更) も指定できます。

=================================================================
=              12.4 マッチモードで囲む                          =
=================================================================

 マッチモードは、選択範囲を区切り文字で囲むのにも使えます。たとえば
 下の行で、
  * i) "select all of this" の部分を選択します (select の先頭に
    カーソルを移動し、v でセレクトモードに入って 4e で 4 単語選択)。
  * ii) ms( または ms) を押して選択範囲を括弧で囲みます。

 --> so, select all of this, and surround it with ()

 ほかの区切り文字でも同じです。下の WORD に ms' を押すと '' で
 囲まれます。""、{}、[] でも試してみてください。

 --> surround this WORD !



=================================================================
=            12.5 マッチモードで囲みを削除する                  =
=================================================================

 md で囲みの区切り文字を削除できます。下の行で () の内側、たとえば
 'x' にカーソルを置き、ノーマルモードのまま md( または md) を押すと
 括弧の組が削除されます。

 --> delete (the x pair of parentheses) from within!

 ほかの種類の囲みも同じように削除できます。

 --> delete (nested [delimiters]): "this" will delete the nearest
 matching surrounding pair.
 --> delete "layers "of" quote marks" too: this will delete the
 nearest previous and following quote marks

 存在しない囲みを削除しようとすると、下部にエラーが表示され、
 何も起こりません。

=================================================================
=            12.6 マッチモードで囲みを置き換える                =
=================================================================

 mr で囲みの区切り文字を置き換えられます。下の行で () の内側、
 たとえば 'x' にカーソルを置き、ノーマルモードのまま mr([ を押すと
 () が [] に置き換わります。

 --> replace the (pair from x within), with something else

 このコマンドはもっとも内側の囲みに作用します。次の行でも試して
 みてください。

 --> some (nested surroundings [can be replaced])
 --> this "works with 'other surroundings' too"

 存在しない組を置き換えようとすると、警告が表示され何も起こりません。


=================================================================
=                        第 12 章のまとめ                       =
=================================================================

 m キーでマッチモードに入ります。ポップアップに操作の一覧が出ます。
 マッチモードでは次のことができます。
  * mm で対応する区切り文字へジャンプする (カーソルが対応する組の
    区切り文字の上にある必要があります)
  * mi( などで、カーソルを囲む組の内側 (区切り文字を含まない中身) を
    選択する
  * ma( などで、外側 (中身と区切り文字) を選択する
  * md( などで囲みの区切り文字を削除する
  * ms( で選択範囲を区切り文字で囲む
  * mr([ で囲みの () を [] に置き換える

=                  第 13.1 章 新しい分割を作る                  =
=================================================================

 ノーマルモードで Ctrl-w を押すとウィンドウモードに入り、使える
 コマンドの一覧が表示されます。

 右半分に空のバッファを縦分割で開くには Ctrl-w nv と押します
 (Ctrl と w を同時に押し、次に n、そして v)。ウィンドウが縦に 2 つに
 分かれ、右半分に新しい空のバッファが開き、カーソルがそちらへ移ります。

 注意: Helicode では、これは VS Code のエディタグループの分割です。

=                第 13.2 章 分割の間を移動する                  =
=================================================================

 Ctrl-w k で上の分割へ、Ctrl-w j で下の分割へ、Ctrl-w h で左へ、

 Ctrl-w w を押します。

 新しいバッファや分割で好きな作業ができます。分割を閉じるには
 Ctrl-w q を押します。右下の分割へ Ctrl-w l のあと Ctrl-w j で移動し、
 Ctrl-w q でその分割を閉じてみましょう。

 現在の分割以外をすべて閉じるには Ctrl-w o です。Ctrl-w nv で
 3 つ目の縦分割を開き、Ctrl-w h を 2 回押して一番左へ移動してから
 Ctrl-w o を押してみてください。



=================================================================
=             第 13.3 章 現在のバッファを分割する               =
=================================================================

 Ctrl-w s で現在のバッファを横に分割し、Ctrl-w v で縦に分割します。
 どちらの分割にも同じバッファが開きます。

 Ctrl-w o で余分な分割を閉じ、1 つの表示に戻せます。











=================================================================
=            第 13.4 章 コマンドで分割する                      =
=================================================================

 :vsplit (短縮形 :vs) と :hsplit (短縮形 :hs) でも、特定のバッファを
 縦 / 横に分割できます。たとえば次のように入力します。

 :vs something

 "something" という名前の縦分割が右に開きます。ここで "something" は
 存在しないファイルなので、その名前の新しいバッファが開きます。
 実在するファイル名を指定すれば、そのファイルが開きます。同じように、

 :hs some_more

 で下半分に "some_more" という名前のバッファが開きます。




=================================================================
=                  第 13.5 章 分割を入れ替える                  =
=================================================================

 :vs hello1 で右に、:hs hello2 で下に分割を開きます。

 hello2 から Ctrl-w K を押すと、上の分割と入れ替わります。これで
 hello2 が上、hello1 が下になります。

 続けて hello2 から Ctrl-w H を押すと左の分割と入れ替わり、hello2 が
 左、チュートリアルが右上になります。Ctrl-w のあと HJKL で、左 / 下 /
 上 / 右のバッファと入れ替えられます。

 チュートリアルの分割に戻り、Ctrl-w o でこの分割だけを残します。





=================================================================
=                  第 13.6 章 分割を転置する                    =
=================================================================

 :vs hello1 で右に、:hs hello2 で下に分割を開きます。

 チュートリアルの分割へ移動し、Ctrl-w t を押すと、この分割から開いた
 縦分割が転置されます。hello1 と hello2 が右ではなく下に来ます。
 もう一度 Ctrl-w t で元に戻ります。

 注意: VS Code ではグループのレイアウト (縦積み / 横並び) を切り替える
       操作になります。






=================================================================
=          第 13.7 章 ファイルピッカーから分割を開く            =
=================================================================

 分割はファイルピッカーからも開けます。Space f でファイルピッカーを
 開きます。文字を入力すると曖昧検索でファイルを絞り込めます。
 上下の矢印で選択を移動します。閉じるには Escape を押します。

 Helicode では VS Code のクイックオープンが開きます。選択したファイルを
 分割で開くには、クイックオープンの機能をそのまま使えます。

 チュートリアルの分割に戻り、Ctrl-w o でこの分割だけを残しましょう。





=================================================================
=                       第 13 章のまとめ                        =
=================================================================

 分割を使うと、同じバッファを複数表示したり、複数のバッファを並べて
 表示したりできます。主なウィンドウ操作は Ctrl-w から始まります。
 Ctrl-w hjkl で分割の間を移動し、Ctrl-w q で分割を閉じ、Ctrl-w o で
 現在の分割以外を閉じます。

 :vs FILENAME や :hs FILENAME でも分割を開けます。









=================================================================
=            第 14.1 章 Helicode ならではの機能                 =
=================================================================

 ここからは、VS Code 上で動く Helicode だけの話です。

 * Space モードの多くは VS Code の機能につながっています。
   Space f ファイルを開く、Space b エディタ一覧、Space / 全体検索、
   Space k ホバー、Space r 名前の変更、Space a コードアクション、
   Space d 問題の一覧、Space ? コマンドパレット。

 * :vsc <コマンドID> で任意の VS Code コマンドを実行できます。
   helicode.keys に書けば好きなキーに割り当てられます。

 * :set / :toggle / :get は Helix の設定名を VS Code の設定に
   対応付けます。例: :toggle line-number relative absolute

 * 既存の Helix の設定ファイルは :config-import で取り込めます。

=================================================================
=            第 14.2 章 git の変更を行き来する                  =
=================================================================

 git 管理下のファイルでは、HEAD との差分を Helix と同じキーで
 たどれます。

 * ]g で次の変更へ、[g で前の変更へ。
 * ]G で最後の変更へ、[G で最初の変更へ。
 * mig / mag でカーソル位置の変更 (hunk) を選択。

 変更を選択したあとは d で元に戻す、y でコピーするなど、ふつうの
 編集操作がそのまま使えます。

 注意: これらは VS Code 組み込みの Git 拡張機能を使っています。
       git 管理外のファイルでは、VS Code の差分移動に切り替わります。



=================================================================
=          第 14.3 章 ターミナルとパネルでも同じキーで          =
=================================================================

 設定 helicode.windowKeysEverywhere が有効なら (既定で有効)、
 Ctrl-w のウィンドウモードはテキストエディタの外でも使えます。
 ターミナル、エクスプローラー、検索結果、Webview のどこにいても
 Ctrl-w h/j/k/l でペインを移動できます。

 設定 helicode.listNavigation が有効なら (既定で有効)、エクスプローラー
 などのリストでも j/k、gg/G、Ctrl-d/Ctrl-u、h/l (折りたたみと展開)、
 / (絞り込み) が使えます。

 Corral 拡張機能を入れていれば、Ctrl-w のウィンドウモードから
 ターミナルのペインやエージェントも同じキーで操作できます
 (Ctrl-w c 新しいターミナル、Ctrl-w a エージェントへジャンプなど)。
 割り当ては Corral の ctrl+b プレフィックスと揃えてあります。
